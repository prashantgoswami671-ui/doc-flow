🔬 Technical Details
Algorithm for 180° Detection:
  1. Render page to canvas at 1.5x scale (optimized for large pages)
  2. Extract pixel data using getImageData()
  3. For each pixel, calculate luminance: 0.299*R + 0.587*G + 0.114*B
  4. Count "dark" pixels (luminance < 200) in three sections:
    • Top third (rows 0 to height/3)
    • Middle third (rows height/3 to 2*height/3)
    • Bottom third (rows 2*height/3 to height)
  5. Calculate ratios: topRatio = top / total, bottomRatio = bottom / total
  6. Detect 180° rotation if: bottomRatio > topRatio + 0.3
  7. Confidence = |bottomRatio - topRatio| (capped at 1.0)
  8. Only report if confidence ≥ 0.25
Why This Approach:
  • ✓ No new dependencies: Uses browser Canvas API and existing PDF.js
  • ✓ Lightweight: Renders at reduced scale for performance
  • ✓ Conservative: 30% threshold avoids false positives
  • ✓ Content-based: Analyzes actual page content, not metadata
  • ✓ Scalable: Works for any image-only document
